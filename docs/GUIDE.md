# Honk Guide — Recipes

Copy-pasteable patterns for everyday backends. Every snippet runs inside
`honk::listen(port) { app => … };` with no per-app `.build` file needed — see
[`QUICKSTART.md`](QUICKSTART.md) for scaffolding and [`API.md`](API.md) for the
complete reference.

> Rule of thumb: blocks (`{ app => … }`) are inlined — never `return`/`break`
> inside them; nest `if`/`else` instead (plain `fn`s called from a block *may*
> `return`). Unused helpers compile away completely, keeping minimal binaries at
> `~150 KiB`.

## Imports (zero `.build` files)

```goose
// Standalone repo (fetched & cached automatically by Goose):
import honk from "ZeDoExter/Honk@v1.0.1";

// Local checkout (generated by `./honk new my-api`):
import honk from "../Honk";
import honk.src.honk_auth.honk_auth;            // opt-in: JWT (HS256) + signed cookies
import honk.src.honk_ws.honk_ws;                // opt-in: RFC 6455 WebSockets
import honk.src.honk_openapi.honk_openapi;      // opt-in: OpenAPI 3.1.0 + Docs UI
import honk_sqlite from "../Honk/sqlite";       // opt-in: SQLite (-lsqlite3)
import honk.src.honk_test.honk_test;            // opt-in: in-memory unit tests
```

## Unified pattern routing & route groups

`app.get`, `app.post`, `app.put`, `app.patch`, `app.delete`, `app.options`, and
`app.all` share one unified zero-copy pattern matcher, and `app.group("/prefix")`
nests cleanly while skipping unmatched subtrees in a single branch:

```goose
honk::listen(honk::arg_port(18080)) { app =>
    app.get("/health", "ok");

    app.group("/api/v1") {
        // Named, indexed, and percent-decoded :params:
        app.get("/users/:name") {
            let name, ok = app.param_dec("name");   // %20 -> space
            if ok { app.ok(name); }
            else { app.json_error(400, "bad encoding"); }
        };

        // Typed i64 segment across all methods (suffixes like /toggle OK!):
        app.get_int("/items/:id") { id => app.json() { j => j.set("id", id); }; };
        app.patch_int("/items/:id/toggle") { id => app.ok_json(); };
        app.delete_int("/items/:id") { id => app.no_content(); };
    };

    // Wildcard tail (/files/a/b.txt -> app.tail == "a/b.txt") + traversal guard:
    app.get("/files/*") {
        if honk::has_dotdot(app.tail) { app.text(400, "Bad Request"); }
        else { app.ok(app.tail); }
    };
};
```

## Lifecycle, CORS, Bearer auth, JSON errors, & `Server-Timing`

```goose
honk::listen(18080) { app =>
    app.json_errors();                  // 404/405/401 answer {"error":...} JSON
    app.server_timing();                // adds `Server-Timing: honk;dur=<ms>`
    app.cors();                         // or app.cors("https://app.example") / app.cors_cfg("https://a.example,https://b.example", …)

    app.get("/public", "open");

    app.group("/admin") {
        app.bearer() { tok =>           // auto-401 if missing/invalid Bearer header
            app.get("/me") {
                app.json() { j => j.set("token", tok); };
            };
        };
    };

    app.after() {                       // runs after 404/405 resolution
        // e.g. inspect finalized `app.status` or attach custom headers
    };
};
```

## Nested JSON, arrays, & field-named validation

Stream nested objects (`j.obj`), nested arrays (`j.arr`), and top-level arrays
(`app.json_list`) directly into `app.res` with zero temporary buffers, and
validate request fields with automatic field-specific `400` errors:

```goose
app.post("/users") {
    app.require_str_len("username", 3, 32) { u =>
        app.require_int_range("age", 13, 120) { age =>
            app.require_bool("accepted_terms") { terms =>
                app.created_json() { j =>
                    j.set("created", true);
                    j.obj("profile") { p =>
                        p.set("username", u);
                        p.set("age", age);
                        p.set("terms", terms);
                    };
                    j.arr("roles") { a =>
                        a.add("member");
                    };
                };
            };
        };
    };
};

app.get("/feed") {
    app.json_list() { a =>
        a.obj() { j => j.set("id", 1); j.set("title", "First"); };
        a.obj() { j => j.set("id", 2); j.set("title", "Second"); };
    };
};
```

Need maximum hot-path throughput with zero DOM nodes? Stream directly with
`json::Reader` (`json::each_member` + `json::finish`).

## In-memory unit testing (`honk::tester()`, zero sockets)

Extract your routes into `fn routes(app: honk::Ctx&)` and test them at
100,000+ req/s in memory without opening a TCP port:

```goose
import std;
import honk from "ZeDoExter/Honk@v1.0.1";
import honk.src.honk_test.honk_test;

fn routes(app: honk::Ctx&) {
    app.get("/users/:name") { app.ok(app.param("name")); };
}

fn main() {
    var t = honk::tester();
    t.get("/users/ada") { app => routes(app); };
    assert(t.status == 200 && t.body() == "ada");
}
```

## JWT (`HS256`), Signed Cookies, & Rate Limiting

Import `honk.src.honk_auth.honk_auth;` for zero-dependency SHA-256 / HMAC-SHA256
JWTs and tamper-proof cookies (`0` bytes in apps that don't import it):

```goose
import honk from "ZeDoExter/Honk@v1.0.1";
import honk.src.honk_auth.honk_auth;

let secret = "replace-with-32-byte-env-secret";

honk::listen(18080) { app =>
    app.json_errors();
    app.rate_limit(60, 60);                     // 60 req/min per socket IP -> 429 + Retry-After

    app.post("/login") {
        app.require_str("username") { u =>
            let tok = app.jwt_issue(secret, u, 3600);
            app.set_signed_cookie("sess", u, secret);
            app.json() { j => j.set("token", tok); };
        };
    };

    app.post("/logout") {
        app.delete_cookie("sess");
        app.ok_json();
    };

    app.group("/me") {
        app.jwt(secret) { claims =>             // verifies HS256 MAC + alg + exp/nbf
            app.get("/profile") {
                app.json() { j => j.set("sub", app.user); j.set("ip", app.real_ip()); };
            };
        };
    };
};
```

## Static files (`sendfile` + `ETag`/`304`) & Single-Binary `embed_file`

```goose
let index_html = embed_file("public/index.html");

honk::listen(18080) { app =>
    // Option A: bake assets straight into the binary (zero external files + ETag/304):
    app.embed("/", index_html, "text/html", "public, max-age=3600");

    // Option B: stream a directory from disk via kernel sendfile + automatic ETag/304:
    app.static_dir_cached("/assets/", "public", "public, max-age=86400");
};
```
Seekable media, conditional caching, and precompressed assets work out of the
box on every static route (`Range`, `If-Range`, `If-Modified-Since`):

```goose
honk::listen(18080) { app =>
    // Video/audio seeking + resume: `Range: bytes=0-1048575` -> 206 + Content-Range
    // (multi-range and garbage fall back to 200; unsatisfiable -> 416).
    app.static_dir("/media/", "public");

    // Single file with explicit caching:
    app.static_file("/sw.js", "public", "sw.js", "public, max-age=86400");
};
```

Precompressed sidecars (no C libraries — build them offline, Honk negotiates):

```sh
gzip -9 -k public/app.js && brotli -q 11 -k public/app.js
# -> app.js.gz / app.js.br served automatically on Accept-Encoding,
#    with -gz/-br ETag suffixes; skipped for Range requests and media types
```

Dynamic bodies (JSON APIs, rendered HTML) compress per request instead —
explicit per route, nothing in the hot path for everyone else:

```goose
import honk_gzip from "../gzip";   // opt-in: links -lz only when imported

honk::listen(18080) { app =>
    app.get("/api/feed") {
        var b: u8[>..] = [];
        // ... serialize JSON into b ...
        app.json_gz(200, b[..]);   // gzip iff >= 1024 bytes + client accepts
    };
};
```

Rules: `json_gz`/`text_gz`/`html_gz` send gzip only when the body clears
`threshold` (default `1024`, pass `0` to always try) AND `Accept-Encoding`
carries an explicit `gzip` token (`q=0` refuses; `*` alone does not count).
Level is zlib's default (`6`); one `malloc`/`free` per compressed response.
Static files should keep using precompressed sidecars (zero per-request CPU).

## Bind control & Unix sockets (zero-TCP proxying)

```goose
honk::listen_at("unix:/run/honk/app.sock", 0) { app => … };  // shared by all HONK_WORKERS
honk::listen_at("127.0.0.1", 8080) { app => … };             // v4 loopback only
honk::listen_at("::1", 8080) { app => … };                   // v6 loopback only
honk::listen_at_workers("unix:/run/honk/app.sock", 0, 4) { app => … };  // explicit N
// HONK_BIND=127.0.0.1 ./main 8080                            // same via env on listen()
```

Rule: the bind spec must be set **before** forking (`listen_at*` /
`$HONK_BIND` do this; bare `honk::workers(n)` + `listen_at` aborts loudly for
unix since a post-fork bind cannot be shared).

Nginx → Unix socket (no TCP, no ports):

```nginx
upstream honk { server unix:/run/honk/app.sock; }
server {
    listen 443 ssl;
    location / {
        proxy_pass http://honk;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

IPv6 trusted proxies (dual-stack `::` is the default bind):

```goose
fn main() {
    let nets, ok = honk::parse_cidrs("127.0.0.1,10.0.0.0/8,::1,fd00::/8");
    honk::listen(18080) { app =>
        app.rate_limit_key(app.real_ip_trusted(nets), 60, 60);
    };
}
```

## Server-Sent Events (`SSE`), Chunked Streaming, Forms, & File Uploads

Stream real-time `text/event-stream` updates or HTTP/1.1 chunked responses with
flat memory (every chunk resets the data-stack top on send), and parse HTML
forms + zero-copy `multipart/form-data` binary uploads:

```goose
honk::listen(18080) { app =>
    // Real-time Server-Sent Events (sets Cache-Control: no-cache + X-Accel-Buffering: no):
    app.get("/events") {
        app.sse() { ev =>
            ev.retry(3000);
            ev.send("connected");
            ev.event("progress", "{\"pct\":100}");
        };
    };

    // Generic HTTP/1.1 Transfer-Encoding: chunked streaming:
        app.stream("text/csv") { s =>
            s.write("id,name\n");
            s.write("1,Ada\n");
        };
    };

    // URL-encoded form (`application/x-www-form-urlencoded` or multipart text field):
    app.post("/contact") {
        app.require_form("email") { email =>
            app.json() { j => j.set("email", email); j.set("note", app.form_or("note", "")); };
        };
    };

    // Zero-copy multipart/form-data file upload (`f.data` slices rx_buf directly):
    app.post("/upload") {
        let f, ok = app.multipart_file("avatar");
        if !ok { app.json_error(400, "missing avatar file"); }
        else {
            app.json() { j =>
                j.set("filename", f.filename);  // client directory paths stripped (RFC 7578 §4.2)
                j.set("ctype", f.ctype);
                j.set("bytes", f.data.len);
            };
        }
    };
};
```

## WebSockets (`RFC 6455`) & OpenAPI `3.1.0` Docs UI (opt-in)

```goose
import honk from "ZeDoExter/Honk@v1.0.1";
import honk.src.honk_ws.honk_ws;
import honk.src.honk_openapi.honk_openapi;

honk::listen(18080) { app =>
    // Non-blocking RFC 6455 server: one callback per message, many idle
    // sockets share one worker (auto Ping/Pong + fragment reassembly).
    // NOTE: read app.param() INSIDE the callback (re-matched every turn);
    // values captured outside would dangle across turns.
    app.ws("/ws/:room") { msg, ws =>
        ws.send_json() { j => j.set("room", app.param("room")); j.set("echo", msg); };
    };

    // OpenAPI 3.1.0 JSON + interactive Scalar Docs UI at /docs:
    app.openapi("/openapi.json", "Todo API", "1.0.0") { spec =>
        spec.op("GET", "/todos", "List todos");
        spec.op_int("PATCH", "/todos/:id/toggle", "Toggle todo");
        spec.op_auth("DELETE", "/todos/:id", "Delete todo");
    };
    app.docs("/docs", "/openapi.json", "Todo API");
};
```

## SQLite (opt-in `sqlite/` package, `BOOLEAN`-aware `sql_json`)

```goose
import std;
import honk from "../..";
import honk_sqlite from "../../sqlite";

fn main() {
    let db = db_connect("todos.db",
        "CREATE TABLE IF NOT EXISTS todos(id INTEGER PRIMARY KEY, title TEXT NOT NULL, done BOOLEAN NOT NULL DEFAULT 0);");

    honk::listen(honk::arg_port(18080)) { app =>
        app.get("/api/todos") {
            app.sql_json(db, "SELECT id, title, done FROM todos ORDER BY id;");
        };
        app.post("/api/todos") {
            app.require_str("title") { title =>
                let id, ok = insert_text(db, "INSERT INTO todos(title) VALUES (?1);", title);
                if !ok { app.json_error(500, "insert failed"); }
                else { app.created_json() { j => j.set("id", id); j.set("title", title); j.set("done", false); }; }
            };
        };
        app.patch_int("/api/todos/:id/toggle") { id =>
            let n, ok = run_int(db, "UPDATE todos SET done = 1 - done WHERE id = ?1;", id);
            if !ok || id <= 0 { app.json_error(400, "bad id"); }
            else if n == 0 { app.json_error(404, "not found"); }
            else { app.ok_json(); }
        };
        app.delete_int("/api/todos/:id") { id =>
            let n, ok = run_int(db, "DELETE FROM todos WHERE id = ?1;", id);
            if !ok { app.json_error(400, "delete failed"); }
            else if n == 0 { app.json_error(404, "not found"); }
            else { app.ok_json(); }
        };
    };
    db_close(db);
    db_shutdown();
}
```

SQLite rules:
- Run schema DDL once in `main` before forking or spawning workers.
- **No SQL injection by construction — if you follow one rule**: SQL text must
  be 100% developer constants; user bytes enter ONLY through `?N` bindings
  (`bind_*`, `insert_text`, `run_int`, `sql_json_one*`, `sql_json_text`).
  NEVER `append`/`format` raw input into SQL — for `LIKE`, bind the pattern
  and escape wildcards with `like_escape` (pair with `ESCAPE '\'`):
  ```goose
  var pat: u8[>..] = [];
  pat.push('%');
  like_escape(query, pat);
  pat.push('%');
  app.sql_json_text(db, "SELECT ... WHERE name LIKE ?1 ESCAPE '\\' ...", pat[..]);
  ```
- **Identifiers need allowlists** (columns/tables/directions can't be bound):
  ```goose
  let col = if by == "name" { "name" } else if by == "age" { "age" } else { "id" };
  let dir = order_dir(dir_param);   // "DESC" or "ASC" only, never raw input
  var sql: u8[>..] = [];
  sql.append("SELECT id, name, age FROM kv ORDER BY ");
  sql.append(col);
  sql.push(' ');
  sql.append(dir);
  app.sql_json(db, sql[..]);
  ```

## Multi-worker scaling & production deployment

- **Zero-code multi-worker (`$HONK_WORKERS`)**: `HONK_WORKERS=auto ./main 8080` or `honk::listen_workers(port, n)`.
- **Graceful shutdown (`SIGINT` / `SIGTERM`)**: closes listening socket immediately, forwards `SIGTERM` to forked workers, and flushes queued outbound bytes up to `2s` before exiting `0`.
- **Reverse proxy (TLS)**: terminate TLS in nginx/Caddy and proxy HTTP/1.1 to `http://127.0.0.1:8080`.
- **Long-lived `stream()`/`sse()` responses pin a worker**: each open stream
  blocks its worker's event loop, so size `HONK_WORKERS >= streams + N`.
  WebSockets do NOT pin (non-blocking turns, 1024 upgrades/worker); idle
  sockets of any kind still time out at 30s, so keep a heartbeat.
- **Rate limiter is edge best-effort**: fixed-window, per-worker (quota
  multiplies by worker count), hash collisions fail open. Enough to slow
  scrapers; enforce strict quotas at your gateway/LB.

## Trusted proxies, request IDs, & access logs (`v0.8.0`)

`app.rate_limit()` keys by the unspoofable socket peer IP. Behind a proxy,
allowlist it and key by the verified chain instead (right-to-left walk — a
client can only spoof entries LEFT of what your proxy appended):

```goose
fn main() {
    let nets, ok = honk::parse_cidrs("127.0.0.1,10.0.0.0/8");  // once
    honk::listen(18080) { app =>
        app.rate_limit_key(app.real_ip_trusted(nets), 60, 60);
        app.after() { app.access_log(); };   // one NDJSON line via a single write()
    };
}
```

- `app.request_id()` echoes a safe `X-Request-Id` or generates `w<worker>-<ns>`.
- Signed cookies: add `Secure` in production —
  `app.set_signed_cookie("sess", u, secret, "Path=/; HttpOnly; SameSite=Lax; Secure")`.
- Custom JWT claims (`iss`/`aud`): `app.jwt_claim_str(claims, "iss")` on the
  verified payload from `app.jwt(secret) { claims => … };`.
